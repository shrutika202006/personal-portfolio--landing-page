# Shrutika Kakade - Personal Portfolio

A responsive one-page portfolio built with semantic HTML5 and CSS3.

## Files
- `index.html` - page structure and content
- `style.css` - styling, Flexbox, Grid and responsive media queries
- `images/` - folder for optional images

## Run locally
1. Open this folder in Visual Studio Code.
2. Install the **Live Server** extension.
3. Right-click `index.html` and choose **Open with Live Server**.

## Before submitting
- Check your details, project descriptions and links.
- Test at 360px, 768px and 1280px widths.
- Push the files to a public GitHub repository.
- Enable GitHub Pages in Settings > Pages.
- Submit the live page link, repository link and a short design decision note.

## Design decision
The portfolio uses a navy, white and purple colour palette to keep the layout professional and readable. CSS Grid is used for skill and project cards, while Flexbox is used for navigation and action links. A media query stacks the layout on smaller screens.
